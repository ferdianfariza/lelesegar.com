Requirement:
PHP 8.2 Ke Atas
Composer 2.8.6
Laravel 12.0 Ke Atas


## 1. Clone this project 
`git clone https://github.com/ferdianfariza/lelesegar.com.git`

## 2. Open file directory and install dependencies
`composer install`
`php artisan migrate`
`php artisan db:seed`

## Run the app
`php artisan serve`
